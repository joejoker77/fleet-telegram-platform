# What is on, and what has slipped

## Pull the view

```
~/work/bin/my-matters --quiet-days 21
```

If their Outlook is connected, add the diary for the week so the answer accounts
for the days they are actually at a desk.

## Turn it into a plan, not a list

A dump of forty deal numbers is no use on a Monday. Order it by what goes wrong
if it is ignored:

1. **Matters where the other side has gone quiet on us** and we are the ones
   who will be chased for it. Name these individually, with the client and how
   long it has been.
2. **Matters waiting on them personally** rather than on the client, the other
   side or the tribunal. This is the list they can actually clear this week.
3. **Client emails not replied to.** Short, specific, embarrassing if missed.
4. **Everything else quiet.** A count, and an offer to list it.
5. **Silent for over a year.** A count. These usually want closing rather than
   chasing, so say that rather than putting them in the week's work.

Finish with the two or three specific things you would do first, with deal
numbers. Not categories: matters.

## Dates

Read out whatever dates are recorded on the matters you are already naming, from
the deal record. That is useful context on a matter in front of them.

**Do not sweep the caseload for missed limitation dates and do not produce a
count of them.** Roughly half the firm's instructed matters have nothing in the
date field at all, and a good number of the rest sit at a stale stage, so any
total is misleading in both directions. If they ask for that specifically, say
plainly that the data is not good enough to answer it reliably yet and that Tom
knows.

## If the list comes back empty

Check access before congratulating them:

```
~/work/bin/check-my-access
```

An empty caseload and a caseload nobody can see look identical from here.
