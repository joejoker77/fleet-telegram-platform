# M5.13 — UsageDashboard (расход токенов в Mini App)

Последний экран M5. Источник данных уже существовал: metering Stop-хук
(`runtime/image/platform/hooks/metering-stop-hook.mjs`, M2.5) шлёт `usage.turn`
с in/out/cache-токенами на каждый ход → audit-collector пишет в PG
`usage_records`. До M5.13 сохранялась только сумма in+out; кеш-токены
(доминирующий объём: десятки тысяч cache-read на ход) терялись.

Токены, не доллары: подписка flat-rate (см. `reference_fleet_billing_subscription`),
экран — видимость fair-use. Самая полезная цифра — «за последние 5 часов»
(окно лимита Max-подписки).

## Состав

1. **Миграция 0002** (`packages/db/drizzle/0002_wooden_mordo.sql`) —
   `usage_records` + 4 nullable bigint: `input_tokens`, `output_tokens`,
   `cache_read_tokens`, `cache_creation_tokens`. Старое поле `tokens`
   (in+out) остаётся и продолжает писаться — строки до миграции не пропадают.
2. **audit-collector** — insert заполняет split-колонки из `usageTurnPayload`.
3. **cp-api** — `GET /usage/summary?days=N` (clamp 1..90, default 30):
   - `days[]` — дневные ряды UTC, zero-filled (без дыр): `{date, in, out,
     cacheRead, cacheWrite, legacy, turns}`; `legacy` = in+out строк без
     разбивки (до миграции);
   - `byModel` — `{model: {tokens, turns}}`;
   - `last5h` — счётчики за последние 5 часов.
   Старый `GET /usage` не тронут (back-compat).
4. **miniapp** — кнопка 📊 в шапке → `UsageDashboard.tsx`:
   - карточки: 5 часов / сегодня / 7 дней (in+out и ходы);
   - CSS-бар-чарт по дням (вход/выход/legacy, stacked) — без чарт-либ;
   - отдельный чарт кеша со своей шкалой (иначе задавит in/out);
   - разбивка по моделям; переключатель диапазона 7д/30д/90д;
   - всё через `t()` (i18n, ru заполнен).

```bash
cd /home/vitaliy/work/fleet-platform/control-plane
```

Порядок важен: миграция ДО рестарта collector (иначе insert с новыми
колонками упадёт — он залогирует ошибку и продолжит, но usage потеряются).

11 проверок: shape, zero-fill 30 дней, clamp 7/90, типы полей, back-compat
старого `/usage`, 401 без токена. Плюс вручную: 📊 в Mini App, после пары
ходов бота сегодняшний столбик растёт, кеш-чарт не пустой.
