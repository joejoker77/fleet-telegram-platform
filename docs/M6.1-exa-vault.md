# M6.1 — Exa-ключ из конфига в OneCLI vault

Первый инкремент M6 «Интеграции» (`11-integrations.md`): убрать инлайн-ключ Exa
из `~/work/.mcp.json` тенанта; реальный ключ живёт только в OneCLI и
инжектится egress-прокси на запросах к `mcp.exa.ai`.

## Отклонение от скетча doc 08

`08-runtime-and-gateways.md:113` предлагал инжекцию query-параметром
(`inject: {query: "exaApiKey"}`). Делаем **заголовком `x-api-key`**:

- проверено с пода 2026-06-12: `mcp.exa.ai` уважает `x-api-key` — неверный
  ключ в заголовке → tool error `401 Invalid API key`, верный → результаты;
- OneCLI-инжекция заголовков уже доказана на git-PAT (github.com), query-
  инжекции у прокси нет — заголовок не требует новых механизмов.

Попутный факт: initialize и базовый `web_search_exa` на `mcp.exa.ai` сейчас
отвечают и анонимно (free tier), но платные инструменты (deep_researcher)
требуют ключ, и полагаться на анонимный режим нельзя.

## Шаги

1. **Operator (root на хосте):**
   ```bash
   bash /home/vitaliy/work/fleet-platform/runtime/install/m6.1-exa-vault.sh
   # спросит ключ (= значение exaApiKey из /home/vitaliy/work/.mcp.json)
   ```
   Скрипт — копия проверенного git-pat-vault.sh: secret `vitaliy-exa-api`
   (host `mcp.exa.ai`, header `x-api-key`), аддитивный bind к `vitaliy-bot`
   с verify-after-set и pre-state для отката.

2. **Bot (в поде):** убрать `exaApiKey=...` из `~/work/.mcp.json`
   (остаются только `tools=...` query-параметры). Текущая сессия продолжает
   работать со старым URL; новая подключится без ключа.

3. **Приёмка** (после следующего рестарта сессии/пода):
   - `grep exaApiKey ~/work/.mcp.json` → пусто;
   - exa-поиск в сессии бота работает (включая `deep_researcher_start` —
     платный инструмент, анонимно недоступен);
   - probe неверного ключа с пода: если прокси **переписывает** заголовок —
     вернутся результаты (инжекция жива); если только добавляет при
     отсутствии — 401 (это тоже ок: рабочий путь — без заголовка).

## Откат

```bash
bash runtime/install/m6.1-exa-vault-rollback.sh   # вернуть pre-state bindings + удалить секрет
# затем бот возвращает inline-ключ в ~/work/.mcp.json (ключ у оператора)
```
