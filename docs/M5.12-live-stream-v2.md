# M5.12 — Live step stream v2: Cursor-style UI + step semantics

Follow-up to M5.11 per Vitaliy's feedback (msg 3030, 2026-06-12): the flat
newest-first JSON dump is unreadable; subagent steps are indistinguishable from
the orchestrator's; usage belongs at the end of a turn, human-formatted.
Reference look: Cursor's agent step panel.

## What changed

### Hook (`runtime/image/platform/hooks/tool-activity-hook.mjs`)

One script, now wired on **three** hook events (branches on `hook_event_name`):

| event        | emits        | payload                                                        |
|--------------|--------------|----------------------------------------------------------------|
| PreToolUse   | `tool.use`   | `{tool, summary, phase:"start", tid, agentId?, agentType?}`    |
| PostToolUse  | `tool.use`   | `{tool, phase:"end", tid, ms?, ok?:false, agentId?…}`          |
| SubagentStop | `agent.done` | `{agentId, agentType, summary: clipped last message}`          |

Key facts (verified against the Claude Code hooks reference):

- `tool_use_id` is present on Pre/PostToolUse → links start↔end (`tid`).
- Hooks fire for tool calls **inside subagents** too; those carry `agent_id` +
  `agent_type` — that's the nesting signal. Main-session events have neither.
- `SubagentStop` fires when a Task/Agent completes (Stop does not); it carries
  `last_assistant_message` → the subagent result one-liner in the UI.

Still: no stdout ever (PreToolUse stdout is a permission channel), exit 0
always, fire-and-forget to the collector socket, NOT an LLM call.

### Wiring (`control-plane/install/m5.12-live-stream-v2.sh`)

Adds the same hook command to `PostToolUse` + `SubagentStop` in the tenant's
`settings.json` (PreToolUse stays from m5.11). ADR-003 authorized-edit flow:
override flag → jq edit → git commit to ~/.claude HEAD → rebaseline → re-arm.
`rollback` removes only the two v2 entries.

### UI (`apps/miniapp/src/components/LiveActivity.tsx`)

Raw events fold into **turn cards**, chronological top-down, follow-mode
auto-scroll (sticks to bottom unless the user scrolled up):

- One human row per step: «🖥 Терминал …», «🔍 Ищет в вебе: …», «💬 Отвечает в
  Telegram», «🧩 Скилл /fact-quest цирк» — raw JSON behind a tap.
- Subagent rows («🤖 Субагент fun-fact-checker: …») nest their inner steps,
  expanded while running, auto-collapsed when done (`▸ N` badge), with the
  subagent's final message as a result line.
- `phase:"start"/"end"` matched by `tid`: spinner while running → ✓/✗ + duration.
- `usage.turn` closes the card with a footer: `fable-5 · ↑2 ↓562 · кеш 68k r/1.3k w`.
- Legacy v1 events (no phase/tid) degrade to instant rows — mixed-version
  streams stay readable.

Nesting heuristic: the first event of a new `agentId` claims the most recent
running Agent row without an assigned type. Exact for sequential workflows;
approximate when several subagents run in parallel (events still group
correctly per agentId; only the host-row pairing can swap). If the Agent start
event was lost (best-effort stream), a host row is synthesized.
